# crmurillo.github.io

Personal journal, built with [Eleventy](https://www.11ty.dev/) and deployed to GitHub Pages via GitHub Actions.

## Layout

Colors and type follow the [Leonids](https://github.com/renyuanz/leonids) Jekyll theme (MIT),
laid out as a single column with a header band holding the name, nav, and social links.
